# Personal site

Plain HTML/CSS/JS. No build step. Hosted on GitHub Pages.

- `index.html` — the homepage (opening screen + menu). Each section has its own page: about, work, books, films, blog. Look for `<!-- EDIT -->` comments.
- `style.css` — colors live at the top under `:root`.
- `posts/` — one HTML file per blog post. Copy `first-post.html` to start a new one.
